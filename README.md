# Локальный бэкенд Neura

API работает на NestJS с адаптером Fastify. Prisma Client использует 10 моделей из существующей схемы PostgreSQL.

База: `localhost:5432/neura`, серверная роль `neura_app`. Пароль находится только в игнорируемом `.env`. Для семейного кабинета нужны миграции 001–003 из ../database.

## Запуск

Рекомендуется Node.js 22+: текущие зависимости cookie требуют эту версию. Первичные интеграционные проверки также прошли на установленном Node.js 20.19.6, но этот runtime не удовлетворяет требованиям всех зависимостей.

Из `neura/server`:

```powershell
npm ci
npm run check:db
npm run dev
```

Во втором терминале из `neura`:

```powershell
npm run dev -- --host localhost --port 5173 --strictPort
```

Открыть http://localhost:5173/account. Используйте именно localhost:5173: APP_ORIGIN должен точно совпадать с origin страницы. Vite проксирует `/api` на 127.0.0.1:3001. Порт API слушает только loopback. Для другой конфигурации поменяйте APP_ORIGIN, перезапустите API. Не расширяйте список разрешённых origin на произвольные сайты.

## Закрытый доступ

Администратор приглашает специалиста или личного участника. Для семейного аккаунта специалист создаёт карточку ребёнка и передаёт родителю персональную ссылку (48 часов). Второго ребёнка можно добавить по новому приглашению на тот же email с подтверждением действующего пароля. Администратор выдаёт ссылку для восстановления (1 час). При смене пароля сессии отзываются.

Специалист назначает игру и/или анкету. По каждому назначению сохраняются отдельные ответы, прогресс и время завершения. Семья видит свои детские профили и задания. Специалист видит прогресс в выбранной карточке.

При первоначальной установке примените SQL 001, 002 и 003 из database под владельцем базы. Администратора создаёт команда npm run admin:create -- email@example.org из server. При переходе с предыдущей версии после миграции 003 один раз выполните node --env-file=.env migrate-grants.js. Роли хранятся в neura.users.account_role. Закрытые демонстрационные файлы в server/materials выдаются через API.

## Проверки

В neura: npm test, npm run build и npm run test:e2e. Для проверок API нужен отдельный тестовый PostgreSQL на 127.0.0.1:55439 с применёнными тремя миграциями. В server выполните npm test и node --import ./register.mjs --test test/family-browser.test.js. Семейный браузерный тест использует собранный интерфейс, NestJS и тестовую транзакцию с откатом.
